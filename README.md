# My recipes

These recipes are written in the [Gram language](https://gram-lang.org) using French.

## Requirements

1. Install Gram CLI either following the instructions on the [official website](https://gram-lang.org), or using [mise-en-place](https://mise.jdx.dev):

    ```shell
    mise install
    ```

2. Install Git hooks:

    ```shell
    lefthook install
    ```

## Compiling recipes

```shell
mise run build
```

or

```shell
mise run clean ::: build
```
