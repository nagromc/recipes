# My recipes

These recipes are written in the [Gram language](https://gram-lang.org) using French.

## Requirements

Gram CLI can be installed following the instructions on the [official website](https://gram-lang.org)

Or using [mise-en-place](https://mise.jdx.dev):

```shell
mise install
```

## Compiling recipes

```shell
gram view crepes.gram
```
